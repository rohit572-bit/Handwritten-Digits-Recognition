# Handwritten-Digits-Recognition
This project focuses on building a machine learning model to recognize handwritten digits (0–9) from the popular MNIST dataset. The goal is to accurately classify digit images by applying data preprocessing, feature extraction, and various machine learning and deep learning algorithms.
The project demonstrates the use of image data handling, model comparison, and performance evaluation techniques commonly used in computer vision tasks. By experimenting with algorithms such as Logistic Regression, Support Vector Machines (SVM), Random Forest, and Neural Networks, the project identifies the most effective model for digit classification.

Key steps:

Loading and exploring the MNIST dataset

Preprocessing and normalization of image data

Feature extraction and visualization

Training and testing multiple classification models

Evaluating model performance using accuracy, confusion matrix, and F1-score

Objective:
To develop a reliable and efficient digit recognition system that can classify handwritten numbers with high accuracy — showcasing the application of supervised learning in real-world image classification tasks.
